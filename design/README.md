# Design-Vorlagen aus Claude Design

Hier kommen die exportierten HTML-Dateien rein — **unverändert**, so wie sie
aus Claude Design kommen. Sie sind die Wahrheit für den Nachbau und werden
nicht deployed (siehe `.dockerignore` / Astro ignoriert den Ordner).

Erwartet:

- `styleguide.html` — Farben, Typo, Abstände, Radien, Schatten, Komponenten
- `startseite.html` — die fertig ausgearbeitete Startseite
- weitere Seiten nach Bedarf

Bildmaterial aus dem Export bitte nach `design/assets/` legen.
