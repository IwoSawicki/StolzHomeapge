# Kunden-Logos

Hier die Logodateien ablegen, dann in `src/data/kundenlogos.ts` importieren
und beim passenden Kunden als `logo` eintragen.

**Format:** am liebsten SVG. Sonst PNG mit transparentem Hintergrund,
mindestens 400 px breit.

**Dateiname:** sprechend und klein geschrieben, z. B. `hepa-baut.svg`,
`dmk-bau.png`.

Ohne hinterlegtes Logo zeigt die Kachel automatisch den Kundennamen als
Wortmarke — die Wand sieht also auch unvollständig ordentlich aus.
